The local MCP server evaluates a JSON scenario on your machine and can explain an individual event with timestamps and source IDs. Its tools are read-only and make no network calls with the data.

Download the MCP server

Setup instructions
  1. Unzip the download and install Node.js 20 or newer.
  2. Run npm ci inside the unzipped mcp folder.
  3. Configure your MCP client to launch node /absolute/path/to/workflow-mcp/mcp/server.mjs over stdio.
  4. Ask it to evaluate the included mcp/sample-workflow.json, then explain a late event.
