# BRIEF - refhealth.consulting

## What This Project Is

Static marketing site for ref(health) Consulting, an independent healthcare
data, analytics, and practical AI consulting firm led by Brad Lumley.

The site sells senior consulting around healthcare data strategy, dbt-centered
analytics engineering, AI-readiness, agentic workflow prototypes, payer/provider
modernization, and fractional data leadership.

## Current State

- Static HTML/CSS site. No build step.
- Homepage rebuilt on branch `update-content-ai-consulting-site`.
- Shared style system replaced with an Impeccable-guided healthcare
  signal-control grid direction.
- Blog listing and article pages updated to share the new navigation, footer,
  typography, and CTA framing.
- `PRODUCT.md` and `DESIGN.md` now record product and design truth.
- Impeccable detector run after implementation. Remaining findings are
  section-level padding warnings that do not match the rendered screenshots.
- Impeccable finish reviewer returned `ship` after mobile touch-target,
  navigation-label, and durable-copy fixes.
- Browser smoke checks passed for homepage, blog listing, and dbt article.

## Key Content Decisions

- Primary conversion goal is revenue, expressed as a paid engagement
  conversation.
- Contact method remains `refhealth.consulting@gmail.com`.
- Current title may be referenced, but the site must state that ref(health) is
  independent and not affiliated with Brad's employer.
- Pager-related AI work is described only as anonymized capability language.
- Public GitHub links are used only for public repositories.
- Private local project evidence may inform capability claims but is not named.
- No customers, revenue impact, prices, testimonials, or certifications were
  invented.

## Research Used

Market scan supported the selected offer lanes: AI-ready data foundations, data
governance, payer modernization, provider data, workflow automation, prior
authorization/interoperability pressure, and responsible AI.

Sources reached during implementation included CMS-0057-F, NIST AI RMF material,
public GitHub repository metadata, and public README content. HHS and LinkedIn
blocked the headless browser.

## What Works

- Homepage opens directly from `index.html`.
- `blog.html` and article pages open directly.
- Google Analytics snippet remains present.
- Navigation anchors resolve to `#offers`, `#ai`, `#proof`, `blog.html`, and
  `#contact`.
- Desktop and mobile screenshots were captured locally under
