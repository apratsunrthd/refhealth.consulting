For data teams

Run the same review in your AI client.

The local MCP server reads a dbt manifest from your machine and returns the same evidence and unanswered questions. It has two read-only tools and makes no network calls with your manifest.

Download the MCP server

Setup instructions
  1. Unzip the download and install Node.js 20 or newer.
  2. Run npm ci inside the unzipped mcp folder.
  3. Configure your MCP client to launch node /absolute/path/to/readiness-mcp/mcp/server.mjs over stdio.
  4. Try the included mcp/sample-manifest.json, then point the server at an approved dbt target/manifest.json.

What this tool cannot see
