Install and try

From download to a useful question

  1. Download the .mcpb file. In Claude Desktop, open Settings → Extensions → Advanced settings → Install Extension… and select it. Restart Claude Desktop if the tool does not appear.
  2. Ask: “Use Healthcare Feed Triage on its included sample. Could this feed support a 24-hour follow-up trigger? Show the evidence and what I should ask the data owner.”
  3. To inspect your own file, give Claude its absolute local path and a delivery target. Example: “Inspect /path/to/events.csv against 48 hours. Which rows need investigation?”

The extension includes a synthetic CSV and a small synthetic FHIR Bundle. It requires no account or API key. Claude Desktop includes the Node.js runtime needed to run the extension.

Supported inputs

Start with one feed

CSV event feed: columns event_id, patient_id, event_type, event_time, and received_at. Timestamps need an explicit timezone. The tool measures event-to-receipt delay, counts events by type, and flags duplicate IDs, invalid rows, and late delivery.

FHIR Bundle JSON: checks Encounter IDs, patient references within the supplied Bundle, and encounter period end times. A FHIR Bundle normally has no feed receipt timestamp, so the tool does not claim to measure delivery latency from meta.lastUpdated.

Files are limited to 10 MB and 20,000 rows or entries. The extension returns aggregate counts and row-numbered findings to Claude, not raw records or patient IDs.

Data boundary

Use synthetic or approved de-identified data.

The extension reads a file on your machine and makes no network call to ref(health). Its findings are sent to Claude for interpretation. Do not use it with PHI unless your organization has approved that use of Claude and this extension. Read the data-handling details.

These checks describe the supplied file. They cannot establish complete cohort coverage, consent, clinical appropriateness, or whether an outreach action happened.
